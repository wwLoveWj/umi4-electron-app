# 知识库审批流程使用说明

## 功能概述

知识库审批流程模块实现了对知识库内容的审批管理，确保只有经过审批通过的内容才能在智能问答模块中被搜索到。

## 主要功能

### 1. 知识库管理

- **新增知识**：新增的知识条目会自动设置为"待审批"状态
- **编辑知识**：可以编辑现有知识条目
- **提交审批**：对于已通过或已拒绝的知识条目，可以重新提交审批
- **筛选功能**：支持按分类、标签、审批状态进行筛选

### 2. 审批管理

- **待审批列表**：显示所有待审批的知识条目
- **审批操作**：支持通过/拒绝操作
- **拒绝原因**：拒绝时可以填写拒绝原因
- **统计信息**：显示待审批总数、今日新增等统计信息
- **搜索功能**：支持在待审批列表中搜索

### 3. 智能问答

- **自动过滤**：只搜索已审批通过的知识库内容
- **实时更新**：审批状态变更后，智能问答会立即生效

## 审批状态说明

- **待审批（橙色）**：新提交或重新提交的知识条目
- **已通过（绿色）**：审批通过的知识条目，可在智能问答中使用
- **已拒绝（红色）**：审批被拒绝的知识条目

## 使用流程

### 1. 提交知识条目

1. 在"知识管理"标签页点击"新增知识"
2. 填写问题、答案、分类、标签等信息
3. 保存后自动提交审批

### 2. 审批知识条目

1. 切换到"审批管理"标签页
2. 查看待审批的知识条目列表
3. 点击"查看"按钮查看详细信息
4. 选择"通过"或"拒绝"操作
5. 如果拒绝，需要填写拒绝原因

### 3. 重新提交审批

1. 在"知识管理"标签页找到已通过或已拒绝的知识条目
2. 点击"提交审批"按钮
3. 知识条目状态变为"待审批"

## 技术实现

### 数据库结构

- 新增 `approvalStatus` 字段：审批状态
- 新增 `submittedBy` 字段：提交人
- 新增 `submittedAt` 字段：提交时间
- 新增 `approvedBy` 字段：审批人
- 新增 `approvedAt` 字段：审批时间
- 新增 `rejectReason` 字段：拒绝原因

### 核心方法

- `getApprovedItems()`：获取已审批通过的知识条目
- `getPendingItems()`：获取待审批的知识条目
- `approveItem()`：审批知识条目
- `search()`：搜索时只返回已审批通过的内容

## 注意事项

1. 新增的知识条目默认状态为"待审批"
2. 只有"已通过"状态的知识条目才能在智能问答中被搜索到
3. 审批操作不可撤销，请谨慎操作
4. 拒绝时必须填写拒绝原因
5. 数据库版本已升级到 v2，会自动迁移现有数据
