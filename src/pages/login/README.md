# 登录界面

这是一个美观大方的登录界面，支持多种登录方式和严格的密码验证。

## 功能特性

### 1. 用户名验证

- 支持邮箱格式：`example@domain.com`
- 支持手机号格式：`13812345678`
- 实时验证格式正确性

### 2. 密码强度验证

密码必须满足以下条件：

- 长度：8-20位
- 必须包含以下至少三种字符类型：
  - 大写字母 (A-Z)
  - 小写字母 (a-z)
  - 数字 (0-9)
  - 特殊符号 (!@#$%^&\*(),.?":{}|<>)

### 3. 密码强度指示器

- 实时显示密码强度等级（弱/中等/强/很强）
- 可视化进度条显示强度分数
- 详细显示各项要求是否满足

### 4. 扫码登录

- 右上角三角形二维码图标
- Hover显示完整二维码
- 点击跳转到专门的扫码登录页面
- 支持二维码刷新和倒计时

### 5. 界面设计

- 渐变背景和毛玻璃效果
- 响应式设计，支持移动端
- 流畅的动画效果
- 现代化的UI设计

## 使用方法

### 1. 密码登录

1. 输入有效的邮箱或手机号
2. 输入符合要求的密码
3. 查看密码强度指示器
4. 点击登录按钮

### 2. 扫码登录

1. 点击右上角三角形图标或切换到扫码登录标签
2. 使用手机扫描二维码
3. 在手机上确认登录

## 技术实现

### 验证逻辑

- 用户名验证：使用正则表达式验证邮箱和手机号格式
- 密码验证：检查长度和字符类型组合
- 实时验证：表单输入时实时显示验证结果

### 样式设计

- 使用Less预处理器
- CSS Grid和Flexbox布局
- CSS动画和过渡效果
- 响应式媒体查询

### 组件化

- 密码强度指示器作为独立组件
- 可复用的样式类
- 模块化的文件结构

## 路由配置

登录页面已添加到路由配置中：

- `/login` - 主登录页面
- `/login/qrcode` - 扫码登录页面

## 注意事项

1. 密码验证规则严格，确保安全性
2. 二维码功能需要后端API支持
3. 样式文件使用Less，确保项目支持Less编译
4. 响应式设计适配不同屏幕尺寸
