# 登录界面

这是一个美观大方的登录界面，支持密码登录和扫码登录功能，具有流畅的切换动画效果。

## 功能特性

### 1. 用户名验证

- 支持邮箱格式：`example@domain.com`
- 支持手机号格式：`13812345678`
- 实时验证格式正确性

### 2. 密码强度验证

密码必须满足以下条件：

- 长度：8-20位
- 必须包含以下至少三种字符类型：
  - 大写字母 (A-Z)
  - 小写字母 (a-z)
  - 数字 (0-9)
  - 特殊符号 (!@#$%^&\*(),.?":{}|<>)

### 3. 密码强度指示器

- 实时显示密码强度等级（弱/中等/强/很强）
- 可视化进度条显示强度分数
- 详细显示各项要求是否满足

### 4. 登录模式切换

- 点击右上角三角形图标切换到扫码登录
- 扫码登录界面点击"返回密码登录"切换回密码登录
- 流畅的左右滑动过渡动画效果
- 扫码登录包含完整功能：二维码生成、状态检测、倒计时等

### 5. 扫码登录功能

- 自动生成登录二维码
- 实时检测扫码状态（等待/扫码中/成功/过期）
- 5分钟倒计时，过期自动提示
- 支持手动刷新二维码
- 扫码成功自动跳转

### 6. 界面设计

- 渐变背景和毛玻璃效果
- 响应式设计，支持移动端
- 流畅的动画效果和过渡
- 现代化的UI设计

## 使用方法

### 1. 密码登录

1. 输入有效的邮箱或手机号
2. 输入符合要求的密码
3. 查看密码强度指示器
4. 点击登录按钮

### 2. 扫码登录

1. 点击右上角三角形图标切换到扫码登录界面
2. 等待二维码生成完成
3. 使用手机扫描二维码
4. 在手机上确认登录
5. 点击"返回密码登录"可切换回密码登录

## 技术实现

### 登录模式切换

- 使用React状态管理登录模式（password/qrcode）
- CSS transform和opacity实现滑动过渡效果
- cubic-bezier缓动函数提供自然的动画感觉
- 绝对定位确保两个界面在同一容器中切换

### 验证逻辑

- 用户名验证：使用正则表达式验证邮箱和手机号格式
- 密码验证：检查长度和字符类型组合
- 实时验证：表单输入时实时显示验证结果

### 扫码登录实现

- 二维码生成使用模拟API，实际项目中需要后端支持
- 定时器实现倒计时功能
- 轮询检查扫码状态
- 多种状态管理：等待、扫码中、成功、过期

### 样式设计

- 使用Less预处理器
- CSS Grid和Flexbox布局
- CSS动画和过渡效果
- 响应式媒体查询

### 组件化

- 密码强度指示器作为独立组件
- 可复用的样式类
- 模块化的文件结构

## 动画效果

### 切换动画

- **持续时间**：0.5秒
- **缓动函数**：cubic-bezier(0.4, 0, 0.2, 1)
- **效果**：左右滑动 + 透明度变化
- **性能**：使用transform而非改变布局属性

### 其他动画

- 页面加载动画：fadeInDown、fadeInUp、slideInUp
- 按钮悬停效果：translateY + box-shadow
- 二维码扫描动画：旋转动画

## 注意事项

1. 密码验证规则严格，确保安全性
2. 二维码功能需要后端API支持
3. 样式文件使用Less，确保项目支持Less编译
4. 响应式设计适配不同屏幕尺寸
5. 切换动画使用CSS transform，性能良好
6. 扫码登录状态检测需要后端配合实现
